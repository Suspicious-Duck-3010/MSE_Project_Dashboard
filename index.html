Scan / inspection methods

[Medium] Abstract-level reading. Read full papers before citing.

MethodSeesStrengthsLimits

Layouts: robot arm + scanner · turntable + fixed scanner · gantry / fixed multi-camera · conveyor stations · inline in the printer · hybrid (surface scan, then CT on doubtful areas).

View planning: coverage path planning, CAD-based, sampling-based, next-best-view (Scott, Roth & Rivest 2003). Analysis: compare scan to STL (deviation map), point-cloud deep learning.

Scan simulation: ray-cast the mesh from virtual viewpoints with range, resolution, hidden surfaces and distance-dependent noise; Gaussian depth noise is the common simple model.

Questions to answer yourself

  • Manufacturing error: which AM process and error types; how each is modeled and sized; how realism is justified.
  • Robot simulation: which robot, sensor, tool; what is simulated (kinematics, reachability, collisions, cycle time).
  • Inspection data: point-cloud format, density, noise; ground-truth virtual data or added noise.
  • Layout: decision variables (robot position, turntable, sensor standoff, viewpoints) and objective (coverage, accuracy, time).
  • Data quality: metrics and what counts as "good".
  • Success criteria: results that go in 15 slides and 6 pages.

The product

MFC anode: porous cube lattice (TPMS-like) made by additive manufacturing. Dataset: 1000 designs, 50/50 manufacturable; variables x1-x6, d1-d4, FEASIBILITY label, STL meshes. The PDF never states the AM process. Data unopened.
